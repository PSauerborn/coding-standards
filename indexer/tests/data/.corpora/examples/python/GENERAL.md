# Fixture Python Standards

`[PY-100]` **MUST**: Configuration must be loaded from the environment.

`[PY-101]` **MUST**: Secrets must never be written to a configuration file.

`[PY-102]` **SHOULD**: Log records should be emitted as JSON.
